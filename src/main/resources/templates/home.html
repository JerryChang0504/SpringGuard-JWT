分散式身分驗證示範專案

本首頁說明專案用途與入口。登入後可進入功能儀表板實際呼叫受保護 API、體驗 JWT 簽發／校驗／刷新， 並透過 Swagger UI 檢視 OpenAPI 文件。

  • ✓Maven 建置、REST API、無狀態 Session
  • ✓JWT：登入簽發 access／refresh、Filter 解析 Bearer
  • ✓角色：USER 個人資料、ADMIN 管理端點
  • ✓springdoc-openapi：Swagger UI 互動測試

內建測試帳號

user ／ password（USER） admin ／ admin（USER + ADMIN）
