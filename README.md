# SpringGuard-JWT
這個實作（Lab）的主題設定為 「安全防線：基於 Spring Boot 與 JWT 的分散式身分驗證實作」。  Lab 目的  主要是引導學習者透過 Maven 管理專案，  從零開始構建一個具備權限控管功能的 Web API 服務，並深入理解 Middleware（在 Spring Security 中稱為 Filter）如何處理請求過濾。  Lab目標  掌握 Maven 專案依賴管理與多模組設定。  理解 JWT (JSON Web Token) 的簽發、校驗與生命週期管理。  實作 Filter Middleware，攔截 API 請求並進行身分合法性檢查。  配置 Spring Security 以保護特定端點（Endpoints）。
